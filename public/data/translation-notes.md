# 아틀리에 온라인 한국어 번역 참고 노트

이 문서는 `stories.json`의 일본어(`ja`)를 기준으로 한국어(`ko`)를 교정할 때 사용하는 단일 기준이다. 기존 `ko` 문장은 신뢰하지 않으며, 줄거리와 앞뒤 대사를 먼저 확인한 뒤 번역한다.

## 작업 원칙

- `[px]`, 줄바꿈, 선택지·분기 구조, 음성·이미지 참조는 원문 그대로 보존한다.
- 선택지 안의 `option.events`도 본문 대사와 같은 수준으로 검수한다.
- 고유명사는 `speaker.ko`의 표기를 기준으로 고정한다. 일본어 음차 1인칭(아타시·보쿠친 등)은 한국어 자연스러운 1인칭과 말투로 옮긴다.
- 원문의 부정·주객·명령을 별도 대조한다. 특히 `死なん`은 “죽지 않는다”, `やぶさかではない`는 “마다하지 않는다”, `～ないわけにはいかん`은 “하지 않을 수 없다”이다.
- 현재 번역을 답으로 삼아 역번역하지 않는다. 항상 `ja`와 같은 장의 전후 사건을 함께 읽는다.

## 인물 말투

| 인물 | 한국어 말투 기준 |
| --- | --- |
| 소렐 | 활달하고 장난기 있는 또래. 기본은 `나/우리`, 친구에게 `-잖아/-거든/-할 거야`, 어른에게는 자연스러운 `-요`. 늘임·감탄은 살리되 남성체와 문어체는 피한다. 헤이즐은 선배로 부른다. |
| 페퍼민트 | 밝고 어린 요정. `나`, `-네/-야/-지!`를 쓰며 반복·늘임을 살린다. 지나친 공손체로 평준화하지 않는다. |
| 아니스 히솝 | 신중하고 온화한 동료. `저`, `-요/-네요/-까요`와 말줄임으로 배려와 망설임을 표현한다. |
| 크레송 | 학원 위사대의 보호자다운 또래 남학생. `나`, `-지/-다/-겠지`; 거칠되 동료에게는 다정하게 쓴다. |
| 위스티리아 | 밝고 진지한 존댓말. `저`, `-요/-습니다`; 17장 전입 뒤에는 일행을 `[px] 선배`, `소렐 선배`처럼 부른다. |
| 안젤리카 | 조용하고 짧은 말, 말줄임이 많다. `나`, 담백한 `-어/-야`; ‘うち’를 ‘우리’로 오인하지 않는다. |
| 발레리안 | 거칠고 시원한 골목말투. `나`, `-지/-잖아/-거든`; 비속어는 꼭 필요한 곳에만 쓴다. |
| 에리카 | 우아한 상류층 말투. `저`, 부드러운 `-군요/-지요/-어요`, “후후”를 유지한다. |
| 헤이즐 | 밝게 웃으며 일을 맡기는 학생회장 선배. `나`, `-잖아/-해 줄래?/-맡길게`; 교장 같은 경직된 존대는 피한다. |
| 마조람 | 다정한 치유 담당 어른. `저`, 친절한 `-요/-거든/-네요`. |
| 오레가노 | 과묵한 관리인. 짧고 묵직한 `나`, `-다/-지`. |
| 루 | 자신만만하고 까칠한 15세 천재. `나`, 어린 남성의 `-지/-거든/-라고`; 유아체·노인체 금지. |
| 스컬캡 | 호쾌하고 의리 있는 두목. 필요할 때만 `이 몸`, `-지/-거든`; 과한 욕설은 피한다. |
| 블랙 코슈 | 의도적 유아 악동체. `나`와 제한적인 “~지롱/~했쪄”, “으햐햐”를 사용한다. ‘보쿠친’을 음차하지 않는다. |
| 칼렌듈라 | 냉정하고 권위적인 선배. `나`, 단호한 `-다/-겠다`; 귀여운 말투·존댓말 금지. |
| 골든로드 | 유쾌한 엘레움 영주. `내가/이 늙은이`, 여유 있는 `-지/-구나/-겠네`. |
| 존스워트 | 장수한 학원장·스승. 절제된 문어체 `나/내가`, `-다/-구나`; 무조건 노인 말투로 만들지 않는다. |
| 레이디스 맨틀 / 레드클로버 | 정의의 히어로·연극풍 과장을 살린다. 등장 구호를 평범한 대사로 낮추지 않는다. |
| 베르가모트 | 엄격하지만 제자를 아끼는 교사. 담담한 권위체 `-다/-거라`. |
| 베르베인 / 스테비아 | 우아한 고급 존댓말. 베르베인은 선장다운 단호함, 스테비아는 부드러운 왕녀다운 어조를 구별한다. |
| 탄드리온 | 왕·상관 앞에서는 `저/제가, -습니다`, 동료 앞에서는 `나/내가, -지`로 전환한다. |
| 나츠메 | 사무라이풍. `소인/이 몸`, `그대/자네`, `-하오/-다`를 절제해 쓴다. |
| 마카 / 치코리 | 자기 이름을 1인칭으로 쓰며 짧은 문장을 유지한다. 마카는 무뚝뚝하게, 치코리는 천진하게 옮긴다. |

## 설정·복선 보호

- 2장에서 일행은 쓰러진 기억상실 소녀를 발견하고, 3장에서 아니스가 눈동자 꽃을 따 ‘위스티리아’라 이름 붙인다.
- 5장의 ‘위타의 아이’는 후반 설정으로 이어지는 고유 표현이다. 임의로 ‘운명의 아이’로 바꾸지 않는다.
- 6~30장의 목표는 지혜의 휘석이며, 30장의 결과물은 진품이 아닌 **검은 지혜의 휘석**이다. 진정한 지혜의 휘석과 혼동하지 않는다.
- 12~14장에서는 코슈가 스컬캡의 청취를 방해하는 마스크에 손댄 정황이 드러난다. 레드클로버의 정체와 기존 인연은 암시만 살리고 앞당겨 밝히지 않는다. 발레리안의 `オヤジ`는 스컬캡을 가리키므로 ‘두목’으로 고정한다.
- 15~17장에서는 블랙 코슈가 에키나세아와 연결되어 스컬캡과 빌베리를 없애려 한 정황, 그리고 정체를 밝히지 않은 인물이 `[px]`의 성장과 유대를 지켜보는 모습이 나온다. 여기서도 정체를 임의로 확정하지 않는다. 위스티리아는 16장까지 `[px] 씨`, 17장의 전입식 뒤부터 `[px] 선배`로 호칭을 전환한다.
- 18~20장의 정체불명 목격자와 베르베인의 전 부하가 보이는 사과는 후속 사실을 앞당기지 않는다. 골든로드와 아마릴리스의 젊은 시절 및 시간 차이에서 생긴 오해도, 해당 장에서 확인되는 감정만으로 옮긴다.
- 21~23장에서도 정체를 밝히지 않은 인물이 `[px]`의 4속성 연금술·‘미래의 싹’·유대를 관찰하고 활용하려는 의도를 비춘다. 정체나 결말을 앞당기지 않는다. 위스티리아가 에메랄드 판을 독단적으로 다루는 사건은 가족 같은 동료 관계를 확인하는 흐름으로 마무리한다.
- 홉은 여성 요정이며 가볍고 활기찬 `-슴다` 말투를 제한적으로 유지한다. 사이드 6장의 시점에는 위스티리아도 이미 `[px] 선배` 호칭을 사용한다.
- 24~28장에서 유성나비가 완전히 멸종하지 않았다는 단서와 아마릴리스·골든로드 관계의 진전은 해당 장에서 확인되는 범위만 옮기며 이후 결말을 앞당기지 않는다.
- 사이드 7~10장의 가면 인물과 에키나세아가 로즈힙 저택에 벌인 공작은 정체를 확정하지 않고 암시로 남긴다. 네틀·안젤리카의 남매 관계와 안젤리카의 동행 결심도 해당 시점까지만 드러낸다.
- 11~13장의 에키나세아는 감형 뒤 속죄하는 흐름이다. 이후 사실을 앞당겨 단정하지 않는다. 조직 호칭 `오야지`는 혈연이 아닌 스컬캡을 가리키는 ‘두목’으로 고정한다.
- 33~36장의 아라=모르스와 약 400년 주기 문명 멸망 관련 사실은 해당 장에서 공개된 범위만 유지한다. 이후 정체·결말을 미리 확정하지 않는다.
- 발레리안의 여행 합류는 스컬캡이 의도적으로 조직에서 내보낸 조치로만 드러낸다. 그 뒤 전개는 앞당기지 않는다.
- 17~19장의 골든로드가 품은 인어 관련 숙원은 정체나 결말을 앞당기지 않고, 해당 시점의 암시만 남긴다.
- 37~40장의 위스티리아의 비정상적 마나, 알모스의 경고, 코슈가 언급하는 부모는 해당 시점의 복선까지만 살린다.
- 사이드 20~21장에서는 인간·요정이 `우니`라 부르는 것을 인어가 `밤`이라 부르는 명칭 차이를 유지한다.
- 사이드 30~36장의 블랙 코슈가 언급하는 문명 멸망과 400년 주기는 후속 정체를 단정하지 않고 암시로만 보존한다.
- 사이드 37~40장의 알모스가 하는 ‘운명의 아이’ 경고, 브레세일 멸망 위협, 코슈·그라키아=루푸스 관련 위기는 해당 시점에서 확인되는 범위만 남긴다.
- 41~45장의 켄트=칼브리아와 레가투스=위타 계획, 호문쿨루스 관련 일지는 장이 진행되는 순서대로 드러낸다. 앞 장에서 후반 사실을 미리 밝히지 않는다.
- 사이드 45장의 버베인 정체 공개와 탄드리온의 약속은 이 장에서 드러나는 범위까지만 옮긴다.
- 사이드 41~43장의 칼렌듈라가 언급하는 ‘천지의 눈’ 열쇠, 스테비아의 옛 지인 탐색, 소렐·버베인의 남매 관계는 해당 시점의 암시와 공개 범위만 지킨다.
- 50~51장은 마나 고갈과 별의 방어 본능, 진정한 휘석으로 여는 공존의 길을 다룬다. 52장에서는 칼렌듈라의 생존과 아카데미 교사 합류가 확정된다.
- 46~49장의 위스티리아 관련 진실은 장이 진행되는 원문 공개 순서를 따른다. `星の命`은 생명이 아니라 별의 명령이라는 뜻으로 옮긴다.
- 9~11장의 정체불명 남자와 에키나세아의 소환 붓, 위스티리아와 마물 출현의 연관은 암시만 유지한다. 번역에서 원인을 미리 단정하지 않는다.
- 3~4장의 요정향 이야기에서는 ‘위타의 아이’와 에메랄드 판을 후반 설정으로 선공개하지 않는다. 판은 지혜의 휘석 레시피로 이어지는 불완전한 파편이라는 단서까지만 드러낸다. 툰베르기아의 인간 경계와 쿠페아의 개방적인 태도도 서로 구별한다.
- 33~36장의 기록은 아라의 연옥과 아라=모르스에 의한 문명 멸망의 반복을 다룬다. `文明を無へと帰す`는 문명을 없애는 뜻이다.
- 45장 이후 레가투스=위타·호문쿨루스·위스티리아의 정체가 단계적으로 드러난다. 앞 장 번역에서 후반 반전을 미리 누설하지 않는다.
- 49~51장은 마나 고갈과 아라=모르스의 방어 본능, 진정한 휘석을 통한 공존의 길을 다룬다.
